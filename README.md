# YouTube Comment Section Blocker (Extension)

Hide the comments section on YouTube to improve your focus and browsing experience.

![Extension Icon](icon.png)

## 🚀 Features

- Automatically hides the comment section on all YouTube video pages
- Lightweight and runs silently in the background
- Works even as YouTube navigates between videos (SPA support)

---

## 📦 Installation

### 1. Clone or Download

Clone the repository or download it as a ZIP and extract it.

### 2. Load the Extension in Chrome

Open Google Chrome and go to: chrome://extensions

Enable Developer mode (top right toggle)

Click Load unpacked

Select the folder where you cloned or extracted this repo (youtube-comment-blocker)

You should now see the extension in your Chrome extension list
